# Karaoke App

An interactive karaoke application that uses speech recognition to match your singing with lyrics.

## How to Use

1. Allow microphone access when prompted
2. Sing along with the lyrics shown on screen
3. Words will explode with particle effects when correctly detected

## Controls

- **P**: Pause/play the song
- **R**: Reset the song to the beginning
- **N**: Manually advance to the next line (for testing)
- **B**: Go back to the previous line (for testing)
- **S**: Jump to a specific timestamp (enter seconds when prompted)

## Technical Details

This app uses:
- p5.js for graphics and audio
- Web Speech API for speech recognition
- Custom particle effects for word explosions

## Browser Compatibility

For the best experience, use Google Chrome or Microsoft Edge as they have the best support for the Speech Recognition API.
